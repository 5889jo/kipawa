# e-GA Website Compliance Matrix

**Audit date:** 1 November 2026  
**Project:** VETA Kipawa ICT Centre website  
**Scope:** Read-only inspection of the current repository working tree. This matrix maps every requirement visible in the supplied audit brief to a checkpoint. The full official e-GA PDF and the exact checklist wording from pages 22–24 were not supplied or independently located; see the scope note below.

## Status and counting rules

- **COMPLIANT** — implementation is evidenced in source and meets the stated checkpoint.
- **PARTIALLY COMPLIANT** — some implementation exists, but an identified gap remains or live operation was not verified.
- **NOT IMPLEMENTED** — no implementation was found in the inspected project.
- **NOT VERIFIED** — source inspection cannot establish the fact (typically hosting, domain, database content, or live behavior).
- **NOT APPLICABLE** — reserved for requirements confirmed not to apply; none were confidently classified this way.
